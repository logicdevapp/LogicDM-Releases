# LogicDM Releases

LogicDM is a free Windows download manager from LogicDev. This repository provides official downloads, release notes and application information.

## Download

- [Download the latest stable release](https://github.com/logicdevapp/LogicDM-Releases/releases/latest)
- [Official website — logicdev.id](https://logicdev.id/product/logicdm)
- Windows 10/11, 64-bit

Open a release and download **LogicDM-Setup-<version>.exe**. Each release describes changes from the previous version under Added, Improved and Fixed. The application also provides offline release history in **About → What’s new**.

## Application source remains private

This is a distribution repository. It does not publish the LogicDM application source code. GitHub automatically generates **Source code (zip)** and **Source code (tar.gz)** for this documentation repository; those archives contain repository documentation, not the LogicDM application source.

The installer includes third-party software with its own licenses. License notices and the required upstream component sources/build instructions accompany the release. **LogicDM-ThirdParty-Sources-<version>.zip** contains third-party component sources, not private LogicDM source.
